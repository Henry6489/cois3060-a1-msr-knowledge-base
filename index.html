Data Sources

Common sources of software engineering data used in Mining Software Repositories research.

Source Data Provided Description
GitHub Repositories, commits, pull requests, issues and stars Software repository and development activity data.
Stack Overflow Questions, answers, tags and user reputation Developer question-and-answer data.
JIRA Issue tracking, sprint data and bug reports Software project and issue tracking data.
App Stores Reviews, ratings and downloads User feedback and application information from app stores.
Travis CI / Jenkins Build logs, test results and deployment data Continuous integration and software build data.
Mailing Lists Developer discussions and archives Archived communication between developers.
npm Registry Package dependencies, downloads and versions Software package and dependency information.

Collection Methods

Method Used For Pros Cons
REST APIs Structured queries using APIs such as GitHub API and Stack Overflow API Structured data and relatively easy automation API limits may restrict data collection
GraphQL Flexible queries such as the GitHub GraphQL API Request only the fields needed Queries can be more complex to design
Web Scraping - Selenium Dynamic websites and sites without suitable APIs Can interact with dynamic web content Slower and more complex than simple HTTP requests
Web Scraping - BeautifulSoup Static HTML parsing Lightweight and simple for static pages Less suitable for highly dynamic websites
Database Dumps Large historical datasets such as GHTorrent and SOTorrent Useful for large-scale historical analysis Datasets can require significant storage
Manual Download CSV exports and one-time data collection Simple for small datasets Difficult to automate and update
